## 📊 Database Schema

### Tables
- **users** - User accounts (id, email, password, name, role, society_id, status)
- **societies** - Society info (id, name, address, city, state, organizer_id)
- **flats** - Flat details (id, society_id, flat_number, owner_id, status)
- **events** - Programs (id, society_id, name, date, time, location, type, organizer_id)
- **income** - Income records (id, society_id, event_id, category, amount, payment_method)
- **expenses** - Expense records (id, society_id, event_id, category, vendor, amount, payment_method)
- **bills** - Bill uploads (id, society_id, event_id, type, file_path, amount, vendor)
- **announcements** - Notices (id, society_id, title, description, date, status)
- **photos** - Event photos (id, society_id, event_id, file_path, caption, album_name)
- **audit_logs** - Action logs (id, user_id, action, module, record_id, created_at)
